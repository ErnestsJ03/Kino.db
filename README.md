# Kino.db BETA

Projekta merkis ir nodrosinat kino datu bazes (filmu, reitingu un atsauču) parvaldibas sistemu, izmantojot Python un SQLite. Lietotne lauj veikt pilnu datu apstradi: pievienot, apskatit, meklet, labot un dzest ierakstus.

Nepieciesamas komponentes

Python 3.x;
sqlite3 modulis (iebuvets Python standarta biblioteka);

Projekta palaisana

Klone repozitoriju un parej uz projekta mapi;
git clone https://github.com/ErnestsJ03/Kino.db.git   ;

cd Kino.db

Parliecinies, ka projekta mape atrodas datu bazes fails Kino.db (vai Kino_skola.db).
Palaid galveno failu:
python main.py

Galvenas funkcijas

Datu pievienosana: Jaunu filmu, reitingu, atsauču pievienosāna;
Datu apskate un meklesana: Ierakstu filtrēšana un meklēšana datu bazē;
Datu labosana un dzesana: Esošo datu rediģēšana un dzēšana;
Datu saglabasana: Visi dati tiek saglabati .db failā un paliek pieejami pēc lietotnes aizvēršanas;

Zinamas problemas

Ja tiek izmantots datu bazes fails Kino_skola.db, faila nosaukumam koda datu bazes savienojuma vieta ir jaatbilst faktiskajam faila nosaukumam;
Ievades kļūdas terminālī var izsaukt izņēmumus, ja netiek ievadīts atbilstošs datu tips;
